# One–two week iPhone checklist

Start with disposable sample records, then keep a JSON backup outside the app each day.

- [ ] Add two vehicles. Set yearly start/end odometers and check business-use percentage against business miles ÷ total odometer miles.
- [ ] Log a manual business trip with start/end, purpose and miles. Try saving without a purpose; it should stay in the form with an error.
- [ ] Save a purpose and frequent trip; reuse them and check the new date is today. Time how long familiar trips take to enter.
- [ ] Enter one-way miles with Round trip enabled; confirm the displayed total and CSV double them exactly once.
- [ ] Record a known route while MileLog stays open. Compare GPS miles with the vehicle odometer. Check denied permission, weak signal and Precise Location off while safely parked.
- [ ] During a sample recording, switch apps/lock the phone; return and resume. The app should warn about the unrecorded gap. End, correct miles if needed, and save. A manual correction should show Manual with original GPS miles in notes.
- [ ] Force-close during a sample GPS trip, reopen, and confirm a recoverable draft. Save or discard it. Never manipulate the phone while driving.
- [ ] Edit a saved trip, then inspect Record history. Delete a sample trip and check totals decrease.
- [ ] Add Personal, Medical and Charitable trips. Personal should stay in the log/CSV and not increase totals.
- [ ] Compare June 30 and July 1, 2026 rates. Try an overlapping rate (must be rejected), an employer rate, and a trip with no matching rate (warning, not an invented estimate).
- [ ] Export CSV to Files and open it on your Mac. Check quotes, commas, multiline notes, parking/tolls and all 17 columns. Amount excludes parking/tolls.
- [ ] Create JSON backup, make a newer edit, and restore the backup. The newer edit should remain and importing twice should not duplicate trips. Try malformed JSON: the current log must stay intact.
- [ ] Long-press Settings → MileLog · MVP 1.0 to save feedback. Export JSON and confirm the note is present. Nothing is sent automatically.
- [ ] Install a new build over the same app, without deleting it, and confirm the log remains. Refresh free signing around day seven.

For each issue, note what you did, expected result, actual result, iOS version, and whether location was permitted/precise. For GPS problems include odometer miles and app miles, plus whether the screen locked or the app was left. At the end, share the feedback notes and representative observations; redact private destinations before sharing backups.
